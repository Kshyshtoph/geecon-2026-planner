## Why I built it?

Although https://2026.geecon.org/ has pretty decent SEO, is informative, and most importantly has amazing agenda I lacked a single functionality on their page - the ability to plan my visit there.

There are multiple talks that I'd like to attend, but I can be only at one place - in this case one room - at a time. I wanted to be able to effectively plan my time there - initially, I wanted to just print out the schedule, but figured I'd waste a bunch of paper for the talks that I'll miss anyway. On top of that, since I only have black and white printer and going for a printing service having 2 sheets of paper is quite riddiculus - I decided to make it accessible on my phone.

## How I built it?

Nothing to brag about here - a single `/plan` with claude code, artisanal copy-pastement of the schedules as HTML from the official page, a bunch of tweaks on theme toggle, locking state, shareable URL, so I can plan on desktop and view on mobile - I could do it by hand in half a day or vibe it out in half an hour. The choice was simple.
The result is a single file containing HTML, CSS and JS - the holy trinity of frontend development. Seems more than enough for what I need it to do.
